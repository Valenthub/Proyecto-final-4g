Este repositorio documenta el diseño e implementación de un **SGSI** basado en la norma **ISO/IEC 27001:2022** y el marco **NIST Cybersecurity Framework**. El proyecto se enfoca en proteger una infraestructura de formación tecnológica, garantizando la **Confidencialidad, Integridad y Disponibilidad (CIA)** de los activos críticos.

## 🚀 Áreas de Especialización

### 1. Gestión Estratégica y Normativa (GRC)
* **Diseño de SGSI:** Creación del marco procedimental para la protección de activos de información, software y humanos.
* **Análisis de Riesgos:** Implementación de una matriz de riesgos para identificar amenazas como *phishing* y accesos no autorizados, evaluando su impacto y probabilidad.
* **SLA (Service Level Agreement):** Definición de tiempos de respuesta y resolución ante incidentes críticos (objetivo de resolución en <8h para casos críticos).

### 2. Ciberseguridad Ofensiva (Pentesting)
* **Auditoría de Red:** Escaneo y enumeración de servicios con **Nmap**.
* **Explotación:** Validación de vulnerabilidades mediante **Metasploit Framework**.

### 3. Ciberseguridad Defensiva y Forense
* **Hardening:** Configuración de firewalls (**UFW/IPTables**) y endurecimiento de sistemas **Linux (Debian/Kali)**.
* **Prevención de Fuga de Datos (DLP):** Estrategias de monitoreo a nivel de red y endpoint para evitar filtraciones de información sensible.
* **Análisis Forense:** Investigación de incidentes y recuperación de evidencias mediante **Autopsy**.
